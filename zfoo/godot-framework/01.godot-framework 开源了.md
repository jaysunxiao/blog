# Storyboard — godot-framework 开源了

## Materials
- User VO / 口播稿 (Chinese) → primary spine and narration source
- Prior speech pack `01.godot-framework 开源了-speech/` → reference only (older cut); this storyboard follows the new script above
- Product claims from VO only: lightweight Godot base (`zfoo` + Autoload `GodotFramework`), Harness Rules, agent skills for image/audio/video pipeline, OpenAI-compatible chat helper, audio feel, async load / scene / scheduler, TCP·WebSocket·HTTP + Router, file logging, single-PCK hot update, unit tests, utils, shipping-oriented framing
- Assumption: audience = indie Godot / AI-assisted game makers evaluating shippable structure vs vibe-coding toys

## Visual Style
- **Medium:** cinematic tech-explain + UI montage (Godot editor, terminal, game viewport, abstract architecture diagrams); occasional tactile gameplay inserts
- **Mood:** hooky and a bit painful at first (debt / chaos), then confident and clarifying; ends open and shipping-forward
- **Color / light:** deep charcoal / slate code surfaces; cyan accent for structure and framework; amber for warnings and debt; cool blue Godot playview glow; soft monitor bloom, not neon overload
- **Camera:** smooth dolly and push-ins on UI; kinetic but readable cuts; occasional top-down “architecture map”; locked-off punch lines for thesis cards
- **Motion energy:** medium — code particles, folder stack reforms, toast and VFX pops timed to VO; avoid seizure flicker
- **Aspect:** 16:9

## Spine
Hook on the dopamine of AI game-making overnight → expose the trap of whole-project vibe coding and unpayable refactors → thesis (AI creates, humans repay) and “toy vs ship” → flip the order: framework base, AI only locals → reveal godot-framework (runtime + rules + media skills) with rapid feature beats → close on open source and the next shippable game. Rough total runtime ~3.5–4.5 min depending on pause and BGM bed.

## Assembly
- **Order:** 01 → 21 sequential (hook → debt → thesis → flip → product → feel/systems → shippers → rules → media → CTA).
- **Rough runtime:** ~4.0–4.5 min VO continuous; leave 0.3–0.6 s breath between denser thesis shots (06–08, 21).
- **VO:** Prefer Chinese master + English alt; speak lengths already matched per shot (~3–4 CN chars/s, ~2–3 EN words/s). If re-record from older `*-speech/` pack, re-TTS against this markdown text, not the prior condensed lines.
- **BGM:** low tension bed 01–07 → resolve into confident pulse from 08; soft lift at 16–21. Duck under VO.
- **SFX:** keyboard / whoosh for chaos shots; clean UI ticks for features; solid “dock” hits for module assembly.
- **Stitch:** hard cut on pain beats (04–05); softer dissolves after framework appears (08+). Optional lower-third only if you later allow on-screen labels—default avoid burned-in text (prompts already ask no overlay).
- **i2v note:** no stills provided; all shots are t2v; if cover or hero stills are generated later, swap Cover + Shot 09–10–21 to i2v from those frames.
