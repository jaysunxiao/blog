# Storyboard — godot-framework 基础框架

## Materials
- Series outline `readm.md` → Episode topics for this cut: 接入 · 目录约定 + 勿改 zfoo · Utils（JsonUtils 重点 + 其余精选/点名）· Log · UnitTest · Alert+Colors / Setting / Scheduler(+StopWatch)
- User framing to explain early: Godot is already very lightweight — why still ship a base framework? Answer spine: engine light ≠ project glue ready; every game still rebuilds logs / settings / alerts / utils / schedule / tests / folder contracts; this framework is a thin shared layer on Godot, not a heavier engine
- User edit notes: drop standalone `gdf` beat; drop Utils toolbelt opener; Utils order: `StringUtils` + `TimeUtils` first, then spotlight `JsonUtils`
- Framework docs / usage facts: copy `zfoo/` → Autoload `GodotFramework` (`res://zfoo/GodotFramework.tscn`) → play; directory split (framework / resources by type / game code); rule “only change `zfoo/` with clear reason”
- Utils featured: `StringUtils`, `TimeUtils` first; then hero `JsonUtils.json_to_object` / `object_to_json` (plain objects with public fields); then `FileUtils`, `RandomUtils`, `ThreadUtils`; also available: `ArrayUtils`, `CollectionUtils`, `NumberUtils`, `NetUtils`, `HttpUtils`, `IdUtils`, `RateLimitUtils` (+ `ReflectionUtils` in tree)
- Log → file at `{user_data}/logs/godot.log`; `Log.info` / `Log.error` with `[{}]` placeholders
- UnitTest → attach `zfoo/gdtest/UnitTest.gd`; same-folder `.gd` scanned; methods starting or ending with `test` (case-insensitive, no args)
- Alert + Colors → `Alert.alert(..., Colors.success / Colors.error)`; Setting → get/set + `save()`; SchedulerBus → `schedule` / `schedule_at_fixed_rate`; StopWatch → `cost_seconds()`
- Prior episode storyboard `01.godot-framework 开源了.md` → visual continuity only (not re-covering full product pitch / CTA)
- Assumption: audience already saw the open-source intro; this episode answers the “why framework” doubt, then teaches the daily base APIs

- **Camera:** smooth push-ins on UI; overhead folder maps; locked-off punch for thesis + API name cards; short kinetic bursts only on Alert / Scheduler hits
- **Motion energy:** medium-low overall (readable code gestures); medium pops for toast / timer ticks
- **Aspect:** 16:9

## Spine
Open on the doubt—Godot is already light, so why a base framework?—answer that the engine’s thinness doesn’t ship project glue, and this layer stays thin on purpose → three-step接入 → directory contract + don’t casually edit zfoo → Utils: StringUtils + TimeUtils first, then JsonUtils hero, other helpers compressed, then name the rest → Log → UnitTest → Alert+Colors / Setting / SchedulerBus(+StopWatch) → close: daily base ready, systems next. Rough total runtime ~2.9–3.3 min.
