# Storyboard — godot-framework 开源了

## Materials
- `godot-framework` README / 项目定位 → lightweight Godot framework + agent skills for building and shipping games（双支柱：运行时 `zfoo/` + agent 侧 skills/rules）
- Quick start：Copy `zfoo/` → Autoload `GodotFramework` → `res://zfoo/GodotFramework.tscn` → have fun → 三步上手核心卖点
- 模块清单（`zfoo/`）：AI（OpenAiClient）/ Alert / Audio·Audios / EffectAnimation2D / Unit tests / HotUpdate（单 PCK 流水线）/ Http / Log / Network（TCP·WebSocket·Router）/ ResourceHelper / SceneHelper / SchedulerBus / Setting / Utils / gdf
- Rules（`.cursor/rules/`）：project-directory-structure（框架 / 按类型资源 / 游戏代码分离）；gdscript-code-style（类型、命名、生命周期 `_`）；karpathy-guidelines（先想清楚、简单优先、外科手术式改动、目标可验证）；godot-framework 用法；skill-dependency-manager（skills 依赖装入 `.dependency/`）
- Skills（`.cursor/skills/` README）：AI（分镜 → TTS）；Audio（trim → denoise → normalize → sample-rate → OGG/WAV）；Image（PNG → 去水印 → 切表 → 抠图 → trim → resize）；Video（去 Gemini/Veo 水印 → 抽音/静音 → OGV）；Other（文件名规范化、commit message）
- 叙事意图：先讲清 **AI 写游戏的优缺点**（局部加速 vs 纯 vibe coding 玩具化；**AI 一时爽，重构火葬场**；**AI 负责创造，人类负责还债**）→ 引出本项目双支柱（框架底座 + rules 护栏 + skills 出货流水线）；中文沟通；完整分镜写入本文件
- 无实拍或 UI 截图附件 → 全片 text-to-video；封面 text-to-image

## Visual Style
- Medium: 科技产品广告 + 轻度运动图形（拟 Godot 风格编辑器壳层、代码面板、轻量 2D 游戏帧、agent 流水线节点）；干净工具片，不做卡通吉祥物
- Mood: 前半犀利吐槽（评论区/技术向嘴感），后半开放自信——「框架扛底座，规则护写法，skills 把素材发出去」
- Color / light: 冷石板灰工作区 + 电青强调；吐槽段允许更硬的对比与红/琥珀预警闪；产品段恢复稳青光
- Camera: 吐槽段剪辑更碎、略压迫推镜；产品段锁定/缓推，UI 利落过渡
- Motion energy: 前中偏动能，模块蒙太奇中等，rules/skills 段偏流水线节奏，终卡沉稳
- Sound feel: 前半轻键盘 + 刺一点的 UI 碎响；后半淡科技垫乐；旁白下 duck
- Aspect: 16:9

## Spine
旁白按 **一条连续论述** 写，镜头间有因果承接，禁止清单式「又一个卖点」跳切感。

**论述链：**  
AI 写游戏很爽（01）→ 但擅场只在局部代码（02）→ 若整盘扔给 vibe coding 就翻车（03）→ 摊开就是屎山/一次性/啰嗦重复（04）→ 更糟的是改不动：**AI 一时爽，重构火葬场**（05）→ 落口袋诀：**AI 负责创造，人类负责还债**（06）→ 所以大多只能叫玩具项目（07）→ 正确姿势：底座先稳、AI 填局部，于是引出 godot-framework（08）→ 接入只要三步（09）→ 底座有了，AI 才该进游戏流程（10）→ 手感 → 场景调度 → 网络 → 日志 → 热更新 → 单元测试 → 日常工具 证明运行时底座（11–17）→ **光有底座不够：rules 给 AI 写法护栏**（18）→ **skills 把素材从生成跑到入库、帮你发出去**（19）→ 开源收尾（20）→ **点破：这条视频本身就是用这套框架做的**（21）。

粗算全片 **约 115–135 秒**。
