# Storyboard — godot-framework 基础框架

## Materials
- Series outline → Episode: 框架接入 · Agent接入 · **重点** JsonUtils · Log · UnitTest · IntegrationTest · then lighter rest (other Utils · Alert/Setting/Scheduler)
- User VO (Shot 03): AI is strong at following norms in mature languages/ecosystems; in a newer domain like Godot there is little to copy or learn from, so overall performance stays mediocre
- User framing: engine light ≠ project glue; AI weak on Godot norms → thin shared framework layer
- User edit notes: drop 目录约定 / 勿改 zfoo; **teaching order priority** JsonUtils → Log → UnitTest → 集成测试, then unimportant remainder
- Framework setup: copy `zfoo/` → Autoload `GodotFramework` → play
- Agent Support: `.cursor/rules/` + `.cursor/skills/`; Cursor / OpenCode native; Codex → `AGENTS.md` + `.agents/skills`; Claude → `CLAUDE.md` + `.claude/skills`
- JsonUtils: `json_to_object` / `object_to_json` on plain objects with public fields
- Log → `{user_data}/logs/godot.log`; `Log.info` / `Log.error` with `[{}]`
- UnitTest → attach `UnitTest.gd`; same-folder `.gd` scanned; methods start/end with `test` (no args)
- IntegrationTest → attach `IntegrationTest.gd`; same-folder `.tscn` whose names start/end with `test` run one-by-one; scene emits `gdf.events.test_passed` to advance; error quits
- Secondary (brief): StringUtils, TimeUtils, FileUtils, RandomUtils, ThreadUtils; Array/Collection/Number/Net/Http/Id/RateLimit; Alert+Colors; Setting; SchedulerBus+StopWatch
- Prior ep01 storyboard → visual continuity only
- Assumption: audience saw open-source intro; this ep answers “why framework”, then base APIs with test/log/json priority
