# Storyboard — godot-framework 开源了

## Materials
- `godot-framework` README / 项目定位 → lightweight Godot framework + agent skills for building and shipping games
- Quick start：Copy `zfoo/` → Autoload `GodotFramework` → `res://zfoo/GodotFramework.tscn` → have fun → 三步上手核心卖点
- 模块清单（仅材料内出现的能力）：AI（OpenAiClient）/ Alert / Audio·Audios / EffectAnimation2D / Unit tests / HotUpdate（单 PCK 流水线）/ Http / Log / Network（TCP·WebSocket·Router）/ ResourceHelper / SceneHelper / SchedulerBus / Setting / Utils / gdf
- 叙事意图：先讲清 **AI 写游戏的优缺点**（局部加速 vs 纯 vibe coding 玩具化；**AI 一时爽，重构火葬场**；**AI 负责创造，人类负责还债**）→ 再引出本项目作工程底座；中文沟通；完整分镜写入本文件
- 无实拍或 UI 截图附件 → 全片 text-to-video；封面 text-to-image

## Visual Style
- Medium: 科技产品广告 + 轻度运动图形（拟 Godot 风格编辑器壳层、代码面板、轻量 2D 游戏帧）；干净工具片，不做卡通吉祥物
- Mood: 前半犀利吐槽（评论区/技术向嘴感），后半开放自信——「AI 补局部，框架扛底座」
- Color / light: 冷石板灰工作区 + 电青强调；吐槽段允许更硬的对比与红/琥珀预警闪；产品段恢复稳青光
- Camera: 吐槽段剪辑更碎、略压迫推镜；产品段锁定/缓推，UI 利落过渡
- Motion energy: 前中偏动能，模块蒙太奇中等，终卡沉稳
- Sound feel: 前半轻键盘 + 刺一点的 UI 碎响；后半淡科技垫乐；旁白下 duck
- Aspect: 16:9

## Spine
旁白按 **一条连续论述** 写，镜头间有因果承接，禁止清单式「又一个卖点」跳切感。

**论述链：**  
AI 写游戏很爽（01）→ 但擅场只在局部代码（02）→ 若整盘扔给 vibe coding 就翻车（03）→ 摊开就是屎山/一次性/啰嗦重复（04）→ 更糟的是改不动：**AI 一时爽，重构火葬场**（05）→ 落口袋诀：**AI 负责创造，人类负责还债**（06）→ 所以大多只能叫玩具项目（07）→ 正确姿势：底座先稳、AI 填局部，于是引出 godot-framework（08）→ 接入只要三步（09）→ 底座有了，AI 才该进游戏流程（10）→ 手感 → 场景调度 → 网络 → 日志 → 热更新 → 单元测试 → 日常工具 证明底座该配齐的（11–17）→ 开源收尾，回扣「先底座再局部 AI」（18）。

粗算全片 **约 95–110 秒**。
